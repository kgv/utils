### 1. Методы объединения кластеров (`method`)

*   **`'single'`** (Метод ближайшего соседа) — расстояние между двумя кластерами определяется как минимальное расстояние между любыми двумя точками из этих кластеров. Склонен создавать длинные, вытянутые кластеры ("цепочки").
*   **`'complete'`** (Метод дальнего соседа) — расстояние между кластерами определяется как максимальное расстояние между их точками. Создает компактные кластеры примерно одинакового размера.
*   **`'average'`** (UPGMA) — среднее расстояние между всеми возможными парами точек из двух кластеров. Хороший компромисс между `single` и `complete`.
*   **`'weighted'`** (WPGMA) — похоже на `average`, но при объединении кластеров разного размера им дается одинаковый вес (размер кластера не влияет на результат).
*   **`'centroid'`** (UPGMC) — вычисляет геометрический центр (центроид) каждого кластера, и расстояние берется между этими центрами.
*   **`'median'`** (WPGMC) — то же, что и `centroid`, но взвешенное (как `weighted`).
*   **`'ward'`** (Метод Уорда) — минимизирует дисперсию (разброс) внутри кластеров. На каждом шаге объединяются те кластеры, которые дают наименьшее увеличение внутрикластерной дисперсии. **Один из самых эффективных и популярных методов на практике.**

### 2. Метрики расстояния (`metric`)

Метрика определяет, как именно измеряется "похожесть" двух строк данных. `scipy` поддерживает огромное количество метрик (они берутся из функции `scipy.spatial.distance.pdist`).

**Классические (геометрические) расстояния:**
*   **`'euclidean'`** — обычное Евклидово расстояние (расстояние по прямой). Используется по умолчанию.
*   **`'cityblock'`** (или `'manhattan'`) — Манхэттенское расстояние. Сумма модулей разностей координат. Менее чувствительно к выбросам, чем евклидово.
*   **`'minkowski'`** — расстояние Минковского (обобщение евклидова и манхэттенского).
*   **`'chebyshev'`** — расстояние Чебышева (максимальная разность по любой из координат).
*   **`'sqeuclidean'`** — квадрат евклидова расстояния.
*   **`'seuclidean'`** — стандартизованное евклидово расстояние (учитывает дисперсию каждого признака).
*   **`'mahalanobis'`** — расстояние Махаланобиса (учитывает корреляцию между признаками).

**Метрики корреляции и углов (часто используются в генетике и химии):**
*   **`'cosine'`** — косинусное расстояние. Смотрит на угол между векторами, а не на их длину. Отлично подходит, если важны пропорции веществ, а не их абсолютное количество.
*   **`'correlation'`** — корреляционное расстояние (1 минус коэффициент корреляции Пирсона).

**Специфические метрики (экология, биология):**
*   **`'braycurtis'`** — расстояние Брея-Кертиса. Очень популярно в экологии и анализе микробиомов (обилия видов).
*   **`'canberra'`** — расстояние Канберры. Чувствительно к значениям, близким к нулю.

**Метрики для бинарных данных (если у вас только 0 и 1 — есть вещество / нет вещества):**
*   **`'jaccard'`** — расстояние Жаккара (доля несовпадающих признаков среди всех присутствующих).
*   **`'hamming'`** — расстояние Хэмминга (доля позиций, в которых векторы различаются).
*   **`'dice'`, `'yule'`, `'matching'`, `'kulsinski'`, `'rogerstanimoto'`, `'russellrao'`, `'sokalmichener'`, `'sokalsneath'`** — различные вариации оценки сходства бинарных векторов.

### ⚠️ ВАЖНОЕ ПРАВИЛО СОВМЕСТИМОСТИ

Не все методы работают с любыми метриками! 

Методы **`'ward'`**, **`'centroid'`** и **`'median'`** математически определены **ТОЛЬКО для Евклидова расстояния**. 
Если вы попытаетесь использовать, например, `method='ward'` и `metric='cosine'`, алгоритм либо выдаст ошибку, либо посчитает полную бессмыслицу.

**Как выбрать для ваших данных (химия/хроматография):**
1. **Стандартный подход:** `method='ward', metric='euclidean'` (отлично группирует образцы с похожим количественным составом).
2. **Если важны пропорции, а не концентрация:** `method='average', metric='cosine'` (сгруппирует образцы, у которых одинаковый *профиль* веществ, даже если один образец был сильно разбавлен).
3. **Если много нулей (вещества часто отсутствуют):** `method='average', metric='braycurtis'`.
