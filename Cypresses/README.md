## Методы объединения кластеров (`method`)

* **`'ward'`**: (Метод Уорда) минимизирует дисперсию (разброс) внутри кластеров. На каждом шаге объединяются те кластеры, которые дают наименьшее увеличение внутрикластерной дисперсии.
* **`'average'`**: (UPGMA) среднее расстояние между всеми возможными парами точек из двух кластеров.

## Метрики расстояния (`metric`)

* **`'euclidean'`**: обычное Евклидово расстояние (расстояние по прямой).
* **`'cityblock'`**: Манхэттенское расстояние. Сумма модулей разностей координат. Менее чувствительно к выбросам, чем евклидово.
* **`'cosine'`**: косинусное расстояние. Смотрит на угол между векторами, а не на их длину. Отлично подходит, если важны пропорции веществ, а не их абсолютное количество.
* **`'braycurtis'`**: расстояние Брея-Кертиса. Очень популярно в экологии и анализе микробиомов (обилия видов: экология, биология).

### 1. DAG: Причинный механизм различий между Объектами

В наблюдательных исследованиях DAG нужен, чтобы отделить реальные биологические отличия объектов от лабораторных искажений (конфаундеров).

Биосинтез терпенов в дереве (Истинный хим. профиль дерева):
* Генетика (хемотип) объекта
* Условия среды: почва, климат
* Сезон сбора, возраст дерева
* Внешний стресс / Вредители на Object

Метрика Percent вторична и является лишь математическим артефактом от Absolute. 

**Где могут возникнуть искажения (ложные различия):**
1. **Эффект массы сырья (Confounder):** Если для `Object A` взяли 10 грамм хвои, а для `Object B` — 15 грамм, то метрика `Absolute` покажет ложное различие. Сравнивать объекты напрямую по `Absolute` опасно без нормировки.
2. **Батч-эффект (Batch effect):** Если `Object 1` анализировали в `Vial 1-10` сегодня, а `Object 2` через месяц, смещение калибровки прибора даст разные `RT` (Retention Time) для одного и того же вещества (`CAS`), что алгоритм может принять за разные компоненты.

### 2. Дерево метрик: Как измерить степень отличия?

Вместо продуктовых метрик мы строим **дерево метрик химического разнообразия и дистанций**. 

#### 🎯 Целевые метрики (Target) — Меры межобъектного различия (Beta-diversity)
Это глобальные показатели того, насколько `Object A` далек от `Object B`.
* **Метрика качественного отличия (Jaccard Distance):** Сравнивает только *набор* компонентов (наличие/отсутствие `CAS`). Помогает понять, есть ли в одном объекте уникальные вещества, которых вообще нет в другом.
* **Метрика количественного отличия (Bray-Curtis или Cosine Dissimilarity):** Сравнивает объекты по векторам концентраций (`Percent`). Учитывает не только состав, но и пропорции.
* **PCA / t-SNE дистанция:** Расстояние между центроидами объектов в многомерном пространстве главных компонент.

#### 🔍 Прокси-метрики (Proxy) — Внутриобъектные характеристики (Alpha-diversity)
Показатели, которыми мы описываем каждый отдельный `Object` или `Tree`, чтобы потом их сравнить.
* **Богатство (Richness):** Количество уникальных `Component` (строк), найденных в дереве/объекте.
* **Доминирующий хемотип:** Суммарный `%` топ-3 компонентов (в вашем примере это *alpha-Thujone, Sabinene, Fenchone*). Различаются ли объекты по главному веществу?
* **Индекс Шеннона/Симпсона:** Метрика равномерности профиля. Объект состоит из 2 веществ по 50%, или из 50 веществ по 2%?

#### 🛡 Контрметрики (Guardrail) — Контроль качества данных
Метрики, которые показывают, что найденные различия — это не лабораторный брак.
* **Отклонение RT и RI:** Дисперсия (variance) `RT` и `RI` для одного и того же `CAS` между разными виалами (`Vial`). Если дисперсия высока, алгоритм сопоставления пиков ошибся.
* **Доля неидентифицированных веществ:** Сумма `%` для строк типа `"н/и RI 965.22"`. Если в одном объекте таких 5%, а в другом 40% — мы не можем их корректно сравнить.
* **Стабильность суммы Percent:** Сумма столбца `Percent` по одному `Tree` всегда должна быть близка к 100%. Если где-то 70%, значит, часть пиков потеряна.

### 3. Признаки для балансировки (стратификации) и построения модели

Чтобы алгоритмы машинного обучения (кластеризация, классификация) или статистические тесты (ANOVA, PERMANOVA) работали корректно, данные нужно правильно сгруппировать:

**Как подготовить матрицу признаков:**
1. **Pivot Table (Широкий формат):** Строки — это сущности `Object + Tree` (конкретное дерево), а столбцы — это уникальные `CAS` (или `Component`, если CAS пуст). Значения в ячейках — `Percent` (лучше, чем Absolute, так как % нормирован на общую массу экстракта).
2. **Заполнение пропусков:** Если вещества в дереве нет (как `2-Hexenal` в 8-й строке или пустые значения в `Percent`), для расчетов дисперсии или дистанций туда ставится `0`.
3. **Объединение изомеров/ко-элюатов:** У вас есть строка `"beta-Myrcene+beta-Pinene"`. В других виалах они могут разделиться. Нужно решить, сливать ли их искусственно по всем объектам для честного сравнения.

**Балансировка выборки при сравнении:**
Если вы хотите статистически доказать, что `Object A` отличается от `Object B`, проверьте:
* Одинаковое ли количество деревьев (`Tree`) отобрано для каждого объекта? (Иначе дисперсия большего объекта "поглотит" меньший).
* Если деревья внутри одного `Object` сильно разнятся (высокая внутригрупповая дисперсия), то межгрупповые различия (между объектами) могут оказаться статистически незначимыми. Для оценки этого используется **PERMANOVA** (мультивариативный дисперсионный анализ).
