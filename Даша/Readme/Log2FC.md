# Log2FC

$$Log2FC = \log_2\left(\frac{\text{Среднее Опыта}}{\text{Среднее Контроля}}\right)$$

* Log2 — логарифм этого отношения по основанию 2.
* FC (Fold Change) — это простое отношение (пропорция) значений: $\text{Exp}_{treatment} / \text{Exp}_{control}$.

Значения Log2FC:

* Log2FC = 0 — изменений нет (экспрессия в обоих образцах одинаковая, так как 2⁰ = 1).
* Log2FC = 1 — уровень экспрессии вырос в 2 раза (2¹ = 2).
* Log2FC = 2 — уровень экспрессии вырос в 4 раза (2² = 4).
* Log2FC = -1 — уровень экспрессии упал в 2 раза (2⁻¹ = 0.5).
* Log2FC = -2 — уровень экспрессии упал в 4 раза (2⁻² = 0.25).

Раньше (по ppm): Log2FC > 0 означал: "При стрессе растение синтезировало больше этой кислоты в абсолютных граммах".
Теперь (по процентам): Log2FC > 0 означает: "При стрессе доля этой кислоты в общем пуле липидов выросла".
