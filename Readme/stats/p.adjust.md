# stats/p.adjust

- [rdocumentation.org](https://www.rdocumentation.org/packages/stats/versions/3.6.2/topics/p.adjust)

- **"holm"**: Holm (1979),
- **"hochberg"**: Hochberg (1988),
- **"hommel"**: Hommel (1988),
- **"BH"** or alias **"fdr"**: [Benjamini & Hochberg (1995)](https://www.jstor.org/stable/2346101),
- **"BY"**: [Benjamini & Yekutieli (2001)](https://doi.org/10.1214/aos/1013699998),
- **"none"**: None

Мы анализируем множество различных компонентов. Функция `multipatt` проводит отдельный перестановочный тест для каждого компонента, чтобы выяснить, является ли он значимым индикатором для какого-либо вида растений или их комбинации. Чем больше кислот мы тестируем, тем выше вероятность получить ложноположительные результаты (ошибка первого рода) просто из-за случайности. Поправка BH (контроль False Discovery Rate, FDR) отлично подходит для таких задач: она убирает ложные срабатывания, но при этом не такая жесткая, как поправка BY.

**Интерпретация**: Если `p.adjust.BH` для конкретного компонента равен, скажем, 0.05, это означает, что среди всех компонентов, которые объявлены значимыми индикаторами, ожидается не более 5% ложных результатов.
**NA в p-value**: Функция их игнорирует и возвращает `NA`, корректируя только реальные числа.
