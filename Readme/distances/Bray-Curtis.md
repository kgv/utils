# Bray-Curtis dissimilarity

- https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.distance.braycurtis.html

$$\frac{\sum_{i=1}^{n} |u_i - v_i|}{\sum_{i=1}^{n} |u_i + v_i|}$$

**Интерпретация**: 0 означает что две выборки имеют одинаковый состав (содержат одинаковые виды в равном количестве), а 1 означает что выборки не имеют общих видов.
