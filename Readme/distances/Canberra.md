# Canberra distance

- https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.distance.canberra.html#scipy.spatial.distance.canberra

$$\sum_{i=1}^{n} \frac{|u_i - v_i|}{|u_i| + |v_i|}$$

It is a weighted version of $L_1$ (Manhattan) distance.

- **Нормализация**: Покоординатная (по каждой оси отдельно)
