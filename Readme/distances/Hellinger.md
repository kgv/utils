# Hellinger distance

- https://docs.cupy.dev/en/stable/reference/generated/cupyx.scipy.spatial.distance.hellinger.html

$$\frac{1}{\sqrt{2}}\sqrt{\sum_{i=1}^{n}(\sqrt{u_i} + \sqrt{v_i})^2}$$

способ математически измерить, насколько сильно одно вероятностное распределение
отличается от другого.

это аналог обычного геометрического расстояния по линейке (евклидова
расстояния), но адаптированный для мира вероятностей и графиков.

Возьмем каждый график и извлечем квадратный корень из значения вероятности в
каждой точке. Теперь приложим эти два новых (сглаженных) графика друг к другу и
посчитаем обычное расстояние между ними в каждой точке (как расстояние между
линиями на бумаге).

**0**: распределения абсолютно идентичны.
**1**: распределения вообще не пересекаются.
