# Significance codes

- "***": p-value between 0 and 0.001 (extremely significant)
- "**": p-value between 0.001 and 0.01 (very significant)
- "*": p-value between 0.01 and 0.05 (statistically significant at the standard α = 0.05 level)
- ".": p-value between 0.05 and 0.1 ( marginally significant / 10% level)
- " ": (space) p-value between 0.1 and 1 (not statistically significant)

- **0..=0.001**: "***"
- **0.001..=0.01**: "**"
- **0.01..=0.05**: "*"
- **0.05..=0.1**: "."
- **0.1..=1**: ""
