# vegan.simper

- [Clarke, K.R. 1993. Non-parametric multivariate analyses of changes in community structure. Australian Journal of Ecology, 18, 117–143](https://doi.org/10.1111/j.1442-9993.1993.tb00438.x)
- [rdocumentation.org](https://www.rdocumentation.org/packages/vegan/topics/simper)

Анализ SIMPER помогает понять, **какие именно виды (или признаки/OTU) вносят наибольший вклад в различия между двумя группами образцов**.

В таблице строки (первый пустой столбец) — это названия ваших видов, генов, микроорганизмов или других признаков, которые вы анализируете. Виды в таблице по умолчанию отсортированы по убыванию их вклада в различия.

Вот подробная расшифровка каждого столбца:

*   **`average` (Средний вклад):**
    Средний вклад данного вида в общую степень различия (dissimilarity, обычно по индексу Брея-Кертиса) между двумя сравниваемыми группами. Чем выше это значение, тем сильнее этот вид отличает одну группу от другой.
*   **`sd` (Стандартное отклонение):**
    Стандартное отклонение вклада этого вида. Оно показывает, насколько сильно варьируется вклад этого вида при попарном сравнении всех образцов из первой группы со всеми образцами из второй.
*   **`ratio` (Отношение average к sd):**
    Это значение рассчитывается как `average / sd`. Это очень важный показатель! Чем выше `ratio`, тем более **стабильно** и последовательно этот вид вносит вклад в различие между группами во всех образцах. Вид с высоким `average`, но низким `ratio` может сильно отличаться только в паре образцов (выбросах), в то время как вид с высоким `ratio` является надежным индикатором различий между группами.
*   **`ava` (Среднее обилие в группе A):**
    Среднее значение обилия (abundance) или концентрации данного вида в первой из сравниваемых групп.
*   **`avb` (Среднее обилие в группе B):**
    Среднее значение обилия данного вида во второй из сравниваемых групп. Сравнивая `ava` и `avb`, вы можете понять, в какой именно группе этого вида больше.
*   **`cumsum` (Кумулятивная сумма):**
    Накопленная доля вклада в общее различие между группами. Значение идет от 0 до 1 (что эквивалентно 0% – 100%). Например, если у третьего вида в строке `cumsum` равен `0.45`, это означает, что первые три вида вместе объясняют 45% всех различий между этими двумя группами.
*   **`p` (p-значение / p-value):**
    Статистическая значимость вклада данного вида. Рассчитывается на основе перестановок (пермутаций), которые вы задали в параметре `permutations=PERMUTATIONS`. Показывает вероятность того, что такой вклад вида в различия мог получиться случайно. Обычно значения $p < 0.05$ считаются статистически значимыми (то есть вид действительно является важным маркером различий между группами).

Виды, у которых высокое значение `average`, высокое значение `ratio` (обычно > 1) и низкое значение `p` (< 0.05). Именно они являются главными "драйверами" различий между вашими группами. А посмотрев на `ava` и `avb`, вы поймете, для какой группы этот вид более характерен.
